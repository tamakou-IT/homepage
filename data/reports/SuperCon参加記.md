# SuperCon参加記

本校として初めて本戦に出場したSuperCon。良い結果を残すことはできませんでしたが、とても貴重な経験になりました。この記事では、参加を通じて得た経験を紹介します。

## SuperConとは

高校生や高専生を対象とした「[Supercomputing Programming Contest](https://www.supercon.cii.isct.ac.jp/attwiki/index.php)」です。「夏の電脳甲子園」や「スパコン」という愛称でも知られています。1995年に始まり、2〜3人のチームで、最先端の科学技術に関する難問を解くプログラムを作成し、その速度と正確さを競います。

本戦は4日間にわたって行われ、2026年はスーパーコンピュータ「富岳」を使用しました。

情報オリンピック（JOI）やパソコン甲子園（PCK）と並ぶ、高校生が出場できる代表的なプログラミング系大会の一つです。個人的には、AIの利用に関する制限がない点も、SuperConの特徴だと感じています。

## 予選

### 問題概要

- 優先順位付投票制（[問題本文](https://www.supercon.cii.isct.ac.jp/attwiki/index.php?plugin=attach&refer=SupercomputingContest2026&openfile=SuperCon2026Yosen.pdf )）

有権者が候補者に順位をつけて投票し、得票数が最も少ない候補者を順に除外して当選者を決める、優先順位付投票制をシミュレートする問題です。

さらに、投票後に有権者の順位が変更されたり、候補者が立候補を辞退したりするクエリが与えられます。それらを順番に処理し、候補者の除外順と当選者を求めます。得票数が同じ候補者が複数いる場合は、番号が最も大きい候補者を除外します。

### 解法

前処理では、有権者ごとに各候補者より上位に置かれた候補者の集合を求め、それを候補者ごとに集計します。さらにSOS DPを使い、候補者の残り方ごとに各候補者が獲得する票数を計算しておきます。

順位変更時は、その有権者の旧順位による票数を該当する集合から引き、新順位による票数を加えます。この処理は `O(2^M)` です。

立候補辞退のクエリでは、辞退者を除いた候補者集合から始め、保存済みの得票数を参照して、最少得票（同数なら番号最大）の候補者を順に除外します。最後に残った候補者を当選者とします。この処理は `O(M^2)` です。

### 感想

AtCoder Beginner Contest（ABC）にも参加したことがなかった僕にとっては、難易度の高い問題でした。

最初は自力で解こうとしました。クエリの意味を調べて理解し、候補者の残り方ごとに得票数を前計算する方法を考えましたが、どのような状態をどのように集計すればよいのか分からず、行き詰まりました。

そこで、Webブラウザー上のChatGPTに解法を相談し、Codexを使って実装しました。

最初の実装では、候補者の集合ごとに、全有権者の票を「その集合内で最も順位の高い候補者」に割り当てて集計していました。SuperCon 2級認定問題では候補者数が `1 <= M <= 4` と少なく、この方法でも処理できました。しかし、予選では `1 <= M <= 13` となり、候補者の集合ごとに全有権者の票を集計する方法では、処理が間に合いませんでした。

そこで改めてChatGPTに相談し、SOS DPを使って得票数を効率よく集計する方法にたどり着きました。

## 本戦

### 問題概要

- できる限り小さい正方形トーラスに3000個の円を敷き詰めよう（[問題本文](https://www.supercon.cii.isct.ac.jp/attwiki/index.php?plugin=attach&refer=SupercomputingContest2026&openfile=SuperCon2026_final_problem.pdf )）
- [問題解説](https://www.supercon.cii.isct.ac.jp/attwiki/index.php?plugin=attach&refer=SupercomputingContest2026&openfile=SuperCon2026_final_kaisetsu.pdf )

半径と初期位置がそれぞれ異なる3000個の円を、正方形トーラスの中にできるだけ密に配置する問題です。

円は初期位置からの移動距離に制約があるため、自由に並べ替えることはできません。一方で、半径の近い円を入れ替えるなど、現実の物理的な移動とは異なる操作も可能です。限られた条件の中で円の配置を工夫し、密度を高めることが鍵となります。
